# 🏋️‍♂️ GYM TRACKER — Application Full-Stack de Suivi de Musculation

Application full-stack moderne pour suivre ses séances à la salle, enregistrer ses exercices, poids, séries et répétitions, et analyser sa progression avec des graphiques et statistiques détaillés.

---

## 🚀 Fonctionnalités

- **📅 Journal de bord des séances** : Consultez toutes vos journées d'entraînement avec le détail des exercices et des séries.
- **✍️ Saisie ultra-rapide** : Formulaire optimisé pour saisir la date, les exercices, les charges (kg), les répétitions et ajouter des séries en 1 clic.
- **📊 Page de Statistiques & Progression** :
  - Volume total soulevé par séance (histogramme chronologique)
  - Courbe d'évolution de la charge maximale et 1RM par exercice
  - Répartition du travail par groupe musculaire (Pecs, Dos, Jambes, Épaules, Bras, Abdos)
  - Tableau des Records Personnels (PR)
- **⚡ Backend REST API** : Node.js + Express avec stockage de données persistant.
- **📱 PWA & Mobile First** : Utilisable directement sur smartphone et ordinateur.

---

## 🛠️ Installation & Démarrage local

```bash
# 1. Cloner le dépôt
git clone https://github.com/BatmanMiyuki/gym-tracker.git
cd gym-tracker

# 2. Installer les dépendances
npm install

# 3. Lancer l'application Full-Stack (Backend API + Frontend)
npm run dev
```

- **Frontend** : http://localhost:5173
- **Backend API** : http://localhost:3001
